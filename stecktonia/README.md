# Стектония — структура симулятора

Статическое веб-приложение без сборки и без серверной части: достаточно открыть `index.html`
(или раздать папку любым веб-сервером).

```
stecktonia/
  index.html          разметка и подключение скриптов
  pages/journal.html  журнал/ведомость преподавателя
  styles/             стили
  scripts/
    core/             ядро: модель сети, консоль, отрисовка
    layers/           последовательные расширения (v3…v110)
    modules/          самостоятельные модули: Linux-терминал, анализатор пакетов, ГИА, коллаборация и др.
```

Все скрипты — обычные (не ES-модули) и подключаются по порядку. Внутренние ключи хранилища и маркеры
форматов (`netlab_*`, `netlab-exam` и т. п.) исторически сохранены для совместимости с ранее
сохранёнными схемами и файлами результатов.
